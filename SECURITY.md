# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| Latest release on `main` | ✅ |
| Older revisions | ❌ — please update to the latest release |

## Reporting a vulnerability

This repository contains Python scripts and 3D mesh files for saddle-tree
design work in Blender.  It does not handle user authentication, network
requests, or sensitive data.

If you discover a security issue (for example, a script that could execute
arbitrary code when a maliciously crafted STL is loaded), please report it
by opening a **private security advisory** on GitHub:

1. Go to the repository on GitHub.
2. Click the **Security** tab.
3. Click **Report a vulnerability**.

Please do not open a public issue for security vulnerabilities.

We aim to respond to security reports within **7 days**.
